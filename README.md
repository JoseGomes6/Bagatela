# Bagatela

Site da Bagatela: criação de websites profissionais low cost para pequenos negócios em Portugal.

## Planos

| Plano | Preço |
|---|---|
| Essencial | 179€ |
| Negócio | 299€ |
| Loja Online | 599€ |
| Manutenção mensal (opcional) | 50€/mês |

## Estrutura

- `index.html`: página completa (HTML, CSS e JavaScript num só ficheiro).

## Antes de publicar

Substituir no `index.html`:

- `[TELEFONE]`
- `[TELEMOVEL]`

## Publicar com GitHub Pages

1. Settings › Pages
2. Source: **Deploy from a branch**
3. Branch: `main`, pasta `/ (root)` › Save
